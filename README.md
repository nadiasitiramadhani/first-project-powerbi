# Data Destinasi Wisata Indonesia (Power BI)

## 📊 Deskripsi
Dashboard ini menampilkan analisis destinasi wisata di 5 kota Indonesia.

## 📌 Insight
- Yogyakarta memiliki destinasi terbanyak (126)
- Bandung berada di posisi kedua (124)
- Kategori Taman Hiburan paling dominan
